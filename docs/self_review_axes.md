# 🧩 Self-Review Axes Guide — QA Synth Pro v2.0

## 🎯 Purpose
This document describes the **five core evaluation axes** (plus optional resonance) used in QA Synth Pro v2.0.  
It serves as a **practical checklist** for translators, trainees, and educators.

---

## [1] Semantic Layout (AC)

**Focus:** Retention of the source text’s semantic core.  
**Questions:**  
- Where is the semantic nucleus (main idea) of the source?  
- Which nodes (subject, predicate, phrase) carry it in the translation?  
- If word order changes, does the logical meaning remain valid?  

**Checklist:**  
- [ ] Key concepts preserved  
- [ ] Subject–predicate maintained  
- [ ] Shifts justified logically  

---

## [2] Structural Flow (LG / RD)

**Focus:** Sentence structure stability.  
**Questions:**  
- Is the subject–predicate trunk stable?  
- Are sentence length, punctuation, and conjunctions appropriate?  
- Are clauses balanced and learnable by models?  

**Checklist:**  
- [ ] Stable trunk structure  
- [ ] Logical clause balance  
- [ ] Smooth flow with punctuation/conjunctions  

---

## [3] Spacetime Dynamics (RD)

**Focus:** Flow of time, causality, and emotion.  
**Questions:**  
- Is the sequence of events or logic preserved?  
- Do temporal markers clarify the flow?  
- Does the reader’s decoding flow match the model’s token flow?  

**Checklist:**  
- [ ] Clear time/causal sequence  
- [ ] Consistent emotional axis if present  
- [ ] Natural reading flow  

---

## [4] Post-Edit (FPE Standards: AC / TM / RD / FL)

**Focus:** Corrections & fluency.  
**Questions:**  
- Were mistranslations corrected?  
- Was unnatural word order fixed?  
- Is the style appropriate for register & medium?  

**Checklist:**  
- [ ] MT errors corrected  
- [ ] Style & register appropriate  
- [ ] Readable for target audience  

---

## [5] Neural Alignment (AI Suitability)

**Focus:** Structural reproducibility for AI corpora.  
**Questions:**  
- Do subject–verb–object relations map clearly?  
- Is the syntax tree shape similar to the source?  
- Is vector alignment preserved?  

**Checklist:**  
- [ ] Clear SVO mapping  
- [ ] Syntax reproducible  
- [ ] Aligned with AI training suitability  

---

## 💭 [Optional] Translation Resonance

**Focus:** Rhythm, imagery, poetic cadence.  
**Questions:**  
- Does the translation “sound aloud”?  
- Does it evoke imagery or flow naturally?  

**Checklist:**  
- [ ] Natural cadence  
- [ ] Evocative / imagery-preserving  
- [ ] Stylistically resonant  

---

## ✅ Summary
- **5 Axes** = Semantic Layout / Structural Flow / Spacetime Dynamics / FPE Standards / Neural Alignment  
- **Optional Axis** = Resonance (style & rhythm)  
- Use as a **practical checklist** for translation self-review and education.
